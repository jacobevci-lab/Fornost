# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to **info@fornostsecurity.com**.

Include, where possible, the affected URL or component, reproduction steps, expected vs. observed behavior, and any supporting evidence. Please do not include sensitive customer or third-party data in reports.

## Scope

This repository contains the public Fornost Security company website. The production site is static and does not provide authentication, account management, payment processing, file upload, or a server-side contact form.

Security reports relating to Fornost products or customer environments should identify the affected product or environment clearly.
